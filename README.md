# ระบบจัดการหน้าร้านอาหาร Wongnai POS by FoodStory (Full Ecosystem)

ระบบ POS ร้านอาหารและระบบเดลิเวอรี่ครบวงจร ดีไซน์และฟังก์ชันเสมือนจริงตามแบบ **Wongnai POS by FoodStory** ใช้งานได้ทันทีในรูปแบบ **Client-Side Web Application** เบ็ดเสร็จ ไม่ต้องติดตั้ง Node.js หรือเซิร์ฟเวอร์ ทำงานได้ทั้งแบบ Offline (LocalStorage) และ Online (Supabase Cloud Database)

---

## 📱 โครงสร้างไฟล์ในระบบ (Multi-Device Ecosystem)

| ไฟล์ | หน้าที่ | อุปกรณ์ที่รองรับ |
| :--- | :--- | :--- |
| **`index.html`** | **ระบบ POS หลักหน้าร้าน** (เปิดโต๊ะ, แคชเชียร์, รับออเดอร์เดลิเวอรี่, จัดการเมนู, สมาชิก, ไรเดอร์) | แท็บเล็ต / iPad / หน้าจอ POS / คอมพิวเตอร์ |
| **`order.html`** | **หน้าสั่งอาหารออนไลน์สำหรับลูกค้า** (เลือกเมนู, เลือกท็อปปิ้ง, ปักหมุดแผนที่ OpenStreetMap, จ่ายเงิน) | สมาร์ทโฟนลูกค้า |
| **`rider.html`** | **หน้าคนขับส่งอาหาร (Rider Portal)** (กดรับงาน, นำทางผ่าน Google Maps, อัปเดต GPS สด, ยืนยันส่งมอบ) | สมาร์ทโฟนไรเดอร์ |
| **`track.html`** | **หน้าติดตามสถานะอาหารสด (Live Tracking)** (ดูลำดับขั้นตอนการปรุง, ดูตำแหน่ง GPS ไรเดอร์บนแผนที่สด) | สมาร์ทโฟนลูกค้า |
| **`supabase_schema.sql`** | **สคริปต์ SQL ครบวงจรสำหรับ Supabase** (สร้างตาราง, Realtime Replication, RLS Policies) | Supabase SQL Editor |

## 🚀 วิธีการเปิดใช้งาน
ดับเบิลคลิกไฟล์ **`index.html`** ด้วยเว็บบราวเซอร์ เช่น Google Chrome หรือ Microsoft Edge เพื่อเข้าสู่ระบบ POS หน้าร้านได้ทันที 100%

- **รหัส PIN เข้าสู่ระบบเริ่มต้น:** `1234` (บัญชี: เจ้าของร้าน / ผู้จัดการ)

## 🗄️ การตั้งค่าเชื่อมต่อฐานข้อมูล Supabase Cloud Database (Optional)
หากต้องการให้หน้าร้าน ลูกค้า และไรเดอร์ ซิงค์ข้อมูลข้ามอุปกรณ์ผ่านอินเทอร์เน็ตได้แบบเรียลไทม์:
1. สร้างโปรเจกต์ใหม่บน [Supabase.com](https://supabase.com)
2. ไปที่เมนู **SQL Editor** แล้วคัดลอกคำสั่งจากไฟล์ **`supabase_schema.sql`** ไปวางแล้วกด **Run**
3. ไปที่หน้า POS (`index.html`) > เมนู **"ตั้งค่า"** > เลื่อนลงไปที่หัวข้อ **"ตั้งค่า Supabase Cloud Database"**
4. กรอก **Project URL** และ **Anon Key** แล้วกดบันทึก ระบบจะเชื่อมต่อฐานข้อมูลคลาวด์และ Realtime อัตโนมัติทันที
